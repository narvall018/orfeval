# Code de conduite

Ce projet adopte le [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/fr/version/2/1/code_of_conduct/).

En résumé, nous nous engageons à faire de la participation à ce projet une expérience
respectueuse et sans harcèlement pour tous, quels que soient le niveau d'expérience, l'identité,
l'origine ou les opinions de chacun :

- critiques portant sur le travail, jamais sur les personnes ;
- langage accueillant et inclusif ;
- attention particulière aux personnes qui débutent en bioinformatique ou en développement.

Tout comportement inacceptable peut être signalé en privé au mainteneur via GitHub
([@narvall018](https://github.com/narvall018)). Les signalements sont traités avec
discrétion.
